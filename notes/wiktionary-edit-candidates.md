# Wiktionary edit candidates

Generated by `bin/compare-authoritative-vs-kaikki --md`. Each section is one entry
in `curated/authoritative_pronunciations.txt` whose pronunciation does not match
Kaikki's filtered Wiktionary snapshot under `corpora/wiktionary/`. Status legend
matches the table the script prints to stdout.

Authoritative ARPAbet is the rhymecrime-canonical pronunciation. IPA from Kaikki is
shown raw, with the original `sounds.tags` (so you can see GA vs RP, accent labels,
etc.). The **proposed GA IPA** is back-converted from the *raw* (pre-normalization)
authoritative phones via `lib/rhymecrime/dict/arpabet_to_ipa.rb`. Treat it as a
starting point: paste, then adjust syllable boundaries, ties, or vowel quality as
you see fit. Two known caveats:

- Flapping is preserved — intervocalic `D` from the authoritative file stays `d` in
  the IPA. Restore phonemic `/t/` for words like `keto`, `whiteout`, `tutti-frutti`,
  `protostar(1)`.
- Affricates render as `tʃ` / `dʒ` without tie bars; add `͡` if your target entry
  uses `t͡ʃ` / `d͡ʒ`.

Comparison treats secondary stress (`2`) as unstressed (`0`); secondary-stress
marking conventions vary too much across Wiktionary editors to be worth chasing.

When a Kaikki entry is just an alt-of stub for a spelling or letter-case variant
(e.g. `mafioso` → `Mafioso`, `papier-mache` → `papier-mâché`), the comparison
trampolines to the canonical entry's pronunciations. Sections that did so are
marked with a *Trampolined via …* line, and the linked Wiktionary URL points at
the canonical page (where the IPA actually lives) rather than the stub. We do
*not* trampoline form-of relationships (plurals, past tenses, comparatives)
since inflected forms have different pronunciations from the lemma.
